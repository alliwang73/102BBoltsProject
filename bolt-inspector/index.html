    Bolt decision rules

    A defect stays visible for several neighbouring tube angles, so a run of failing frames means BAD. A lone failing frame is treated as noise. For the share rule, a CHECK frame counts as half a failure. If most frames show no bolt, the call is EMPTY. If a bolt is seen but too few frames can be read, the call is BAD, so an unreadable bolt never reaches the good bin.

      Setting up the camera

      1. Mount the phone or webcam side-on to the tube, with the threads in sharp focus and filling most of the frame.
      2. Put a plain, contrasting backdrop behind the bolt. A backlight gives the crispest silhouette.
      3. Tap Set inspection area, then drag a box around the bolt's position in the tube. Leave out the tube walls and the flap, so the bolt is the only large object.
      4. Run one bolt you know is good, check that it reads PASS in most frames, and save it as the good reference.
      5. Live camera needs https or localhost. On a phone, open the hosted page and use Connect Bluetooth. On a laptop, open this file directly and use either connection.

      What it checks

      • Stripped / flattened: tooth depth below half the bolt's median.
      • Cross-threaded: crests knocked off the helix grid, or lopsided teeth.
      • Missing or truncated crests, uneven pitch, bent or tapered shank.
      • Not helical: top and bottom crests should sit half a pitch apart.
      • Wrong pitch against 1/4-20 (1.27 mm) or a saved good bolt.

      Limits

      It reads the outline only. One frame sees two flanks, so the tube's rotation and the many frames are what cover the whole bolt. Damage on the face toward the camera (pits, surface marks) does not change the outline and goes unseen. An unthreaded shank section reads as missing threads.
