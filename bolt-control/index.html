Tuning

Wiring check (open-loop)

Drives the motor with no feedback for 1 s. Positive PWM must make the counts go up. If the motor spins the wrong way, tick "Reverse motor". If the counts run backwards, tick "Reverse encoder".

Calibrate counts per revolution

1. Mark the output shaft. 2. Tap Start (the motor goes limp). 3. Turn the shaft exactly one full turn by hand. 4. Tap Done, then Save to flash.
